# Playable Ad Validator

Free web tool to validate, preview and convert HTML5 playable ads for 9 ad networks
(AppLovin, Unity Ads, Google, Meta, Moloco, Mintegral, TikTok, Liftoff, generic MRAID).

**Open it:** https://devirosnguyen.github.io/playable-validator/

Files never leave your browser: the page is static and has no backend.

This repository only holds the built site.
